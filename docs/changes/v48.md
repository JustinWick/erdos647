# v48

Record the accepted v47 endpoint and promote seven Mathlib-only elementary
modules to the root package. Preserve old imports with forwarding modules.
Add opt-in core elementary and public analytic/endpoint facades, public examples,
a core elementary audit and a public endpoint audit. Preserve every accepted
proof body, definition, theorem header and all 30 predecessor audit files.

Root `core` checks now cover the independent elementary API. The full suite is
30 gates; the original seven research elementary checks remain compatibility
checks. Result names use v48. Historical acceptance is recorded separately from
new-layout acceptance. No compiler, dependency, cache or CI changes.
